# Digital Daily — Digital Marketing Blog

A responsive static blog website suitable for a college digital marketing project.

## Pages
- index.html — Home
- blog.html — Blog archive + category filtering
- article.html — Full featured article
- about.html — About page
- contact.html — Contact page with demo form

## Features
- Responsive design
- Modern typography and layout
- Dark mode
- Mobile navigation
- Blog category filters
- Newsletter interaction
- Contact form interaction
- SEO-friendly page titles/descriptions
- No backend required

## Hosting
Upload the complete folder to GitHub Pages, Netlify, Vercel, or any static hosting service. Keep the folder structure unchanged.
